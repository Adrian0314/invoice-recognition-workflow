    运行日志 
    
    
    
  
    

  
  
    
    
    它是怎么工作的
    
    
    
      这个页面在浏览器里通过 Pyodide（编译成 WebAssembly 的 CPython）直接运行本仓库的
      optimized_python/idle_invoice_bot.py —— 跑的就是仓库里那个引擎本体，
      不是另写一份简化版。识别规则、校验规则、置信度模型、重复拦截逻辑完全一致。
    
    
    
    
      引擎的“零依赖路径”（内置标准库 PDF 解析器）只用 Python 标准库，
      所以能原样在 WASM 里跑；因此本页面的识别结论与本地运行
      python optimized_python/idle_invoice_bot.py -i invoices_input -o output 一致。
    
    

    
    本页面的能力边界
    
    
    
      
    类型在线版说明
    
      
        
    电子发票 PDF（有文本层）完整支持号码、日期、购销方、金额三项、税率、明细等都能识别
    
        
    无文本层扫描件 PDF登记为待人工录入需要 OCR，浏览器内没有推理引擎
    
        
    图片发票（PNG/JPG）登记为待人工录入同上
    
          
    
    
    
    
      想要 OCR：在本地跑 python optimized_python/idle_invoice_bot.py，
      并先装 rapidocr + onnxruntime + PyMuPDF。
      仓库根目录的 README.md 与 使用手册.md 有完整步骤。
    
    

    
    隐私
    
    
    
      发票文件不会离开你的电脑：文件被读进浏览器的内存文件系统，
      由本地运行的 Python 处理，页面不发任何请求上传它们。唯一的网络请求是首次加载
      Pyodide 运行时（11.6 MB，来自公共 CDN）。
    
    
    
    * 首次加载后运行时会被浏览器缓存；在离线状态下重新打开通常仍可用，取决于浏览器缓存策略。
